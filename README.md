# Online Store Sales Analysis

## Project Overview

This project analyzes an online store's sales data using SQL to understand sales performance, customer behavior, and product revenue.

## Database Tables

* **Customers:** Customer information.
* **Products:** Product names, categories, prices, and stock.
* **Orders:** Customer orders, product quantities, and order dates.

## SQL Analysis

* Calculate total revenue by product.
* Identify best-selling products.
* Analyze daily sales.
* Calculate the number of orders per customer.
* Calculate average order value.
* Compare revenue across product categories.
* Identify the top 3 products by revenue.

## Tools Used

* SQL
* PostgreSQL
* Visual Studio Code

## Skills Demonstrated

* SELECT statements
* JOIN operations
* Aggregate functions (SUM, COUNT, AVG)
* GROUP BY and ORDER BY
* Business data analysis

## Project Goal

To extract useful business insights from sales data and support data-driven decision-making.
